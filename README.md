# MMA3001Project
This repo contains my MMA3001 project. The purpose of this project is to develop a framework in which Air Brakes control algorithms for low altitude sounding rockets can be quickly evaluated.

It contains a one degree of freedom (1DOF) simulation of a sounding rocket written in python. Provided with a set of initial conditions and atmospheric parameters, it will
extrapolate the trajectory of the rocket up to apogee. It uses an RK2 approach to improve processing time.
Different control algorithms can easily be used in the simulation by way of passing in a function as an argument.

The primary files are:
- **analyseSaturnData.py:** Utilities to analyse the raw SATURN data before it is processed.

- **scrubData.py:** Utilities to convert a raw SATURN data frame into a smaller csv format with few columns and rows.

- **Simulation/simulation.py:** The code required for 1DOF simulation

- **evaluateSim.py:** Evaluation functions which will compare the final apogee and trajectory between the ground truth data from SATURN and the 1DOF simulation.

- **timeSim.py:** Code to run a profiler on the 1DOF simulation and evaluate it's average execution time

- **genDataSet.py:** Generates sets of initial conditions and training data for the controllers. The training data contains, for a given rocket state, the optimal extension value calculated using the false position method.

- **controllers.py:** The control algorithms which are to be test, along with the required training functions for each.

- **evalControllers.py:** Runs the controllers on the validation or testing initial conditions generated by genDataSet.py and displays the relative performance between them.

## Installation Instructions
1. Open a terminal in the folder in which you want to the project files to be created
2. clone the repository using:
```
git clone https://github.com/IgbyMcLaverty/MMA3001Project.git
```
3. Enter the folder created by the clone (MMA3001Project)
4. In the terminal create a new venv virtual environment using
```
python -m venv .venv
```
5. Activate the virtual environment in your terminal
```
.\.venv\Scripts\activate
```
6. Install the required python modules using:
```
pip install -r requirements.txt
```
7. Download the [SATURN data](https://drive.google.com/drive/folders/1sgDw-d8G8MQ--V1Cvb-YPGHHRYdABUN9?usp=sharing) and place it into the With_Airbrakes and Without_Airbrakes folders

Run the following command to automatically generate the html documentation files
```
.\makeDocs.ps1
```
To update the pytest report run:
```
pytest –html=docs/pytestReport.html
```
If new modules are imported, use the following command to update requirements.txt
```
pip freeze > requirements.txt
```
